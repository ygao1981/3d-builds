# 货站工艺演示

首页是同一坐标系下的主站房物流作业区。点场内标签进入对应工位。左下角的散件和板货流程可以直接跳到收货计量、收货安检、斜向供包、滑槽卸载、叉车送料、组板和整板交接。

在「主站房全景」点散件流程里的「收货安检」，可以跟看计量后的同一件纸箱进出货物 X 光机。机旁设判图台和人工复核台，开箱的纸箱用来说明按需复核。设备类别依据 PR0020-F1005 至 F1007，机体外形和工位摆放采用示意模型。海关查验在 PR0020-F1014 中另列。右下角「回到全场」可返回总览。

主站房全景默认可自由浏览。左键拖动旋转，右键拖动沿地面平移，滚轮朝指针位置缩放。点一下三维场景，用 W / S 前后移动、A / D 左右移动、Q 降低或 E 升高观察位置。触屏可单指旋转、双指平移或捏合缩放。进入工位或查看图纸再回到全景，会恢复刚才手动调整的位置。点「回到全场」可重新看见整座站房。`node check_cargo_camera.mjs` 可验证这些操作。

在「自动分拣环线」点「分流排队」，可以跟看同一纸箱从公共分配皮带进入分支，经过排队和五段供包后交给环线小车。

点「斜向供包」可以从排队带末端开始看一次交件。选「供包台 1 / 2 / 3」时视角与工艺平面图同向。在供包台复核版布局中，纸箱先沿排队带向图面下方走，再转向左下方，经过五排并列短带和斜口窄带，最后随小车沿主线运行。设备资料里的供包台尺寸来自图面量测。

同一页面左上角可选「上下层同看」「上层分拣环线」或「下层空托盘」。下层视图在原位显示拆盘机、旋转台、横向输送链和九条滚筒支路。点「横向链条输送」可跟看托盘移动。切层会保留播放进度、暂停状态与倍速，设备定位、回放及对应图纸随选择更新。

三维中可旋转、平移、缩放、定位设备、暂停和调整倍速。「空托盘系统」以剖视显示环线下方的拆盘机、旋转台、两组横向输送链和顶升滚筒。「装卸交接」和「组板作业」先呈现正在作业的工位，可在定位菜单中选择全部月台或全部台位。图纸模式按原方向俯视，「图纸叠合」另显示设备轮廓与输送线中心线。

固定设备和工位通过本机项目数据配准。叉车、货厢剖面、组板装载状态、屋架外观和演示时序用于说明作业，图中的其他工艺占区用地面斜线概括。散件和板货分别展示其交接方式。

## 运行

以下命令在本作品的 `src` 目录下运行。新电脑需要 Node.js 和本地项目配套 ZIP。解压到 `src`，使 `public/project-layout/layout.json`、同目录的 PNG 和 `public/simready/` 中的模型就位。

```powershell
npm ci
npm run assets -- --check
npm run dev
```

打开 [本机货站演示](http://127.0.0.1:5426/)。首页显示主站房物流全景，右下角可切换到「重点工位联动」。在「滑槽卸载」选择「格口人工码盘」，可看到下层支路送来的托盘接货。在「装卸交接」可分别回放平台升降和整板交接。当前图纸数据随复核版配套资料提供。

若需重新准备模型，执行 `npm run assets -- --download`，或用 `npm run assets -- "模型库目录"` 从本地带有 `glb` 子目录的资产库复制。准备程序按锁定版本和 SHA-256 校验文件。两个入口共用十份模型。货车内的木托盘使用 SimReady，空托盘线的平面塑料托盘按项目设备表建模。

发布版本在同一目录运行 `npm run build` 和 `npm run preview`，地址和开发版相同。两种启动命令共用同一端口，每次运行一种。打开页面后会显示项目名称。若看到项目资料缺失提示，补齐配套资料后重新加载。

## 验证和录像

从「自动分拣环线」的设备定位菜单选「排队与供包接头」可放大三路斜接面。选择「分配线末端滑板」可查看高、低两条分配线的端部。首页点「下层空托盘」可原位剖看下层设备。在「全景场地复核版」配套资料下，首页默认显示全站房物流范围。点击地轨、AGV 暂存、待运与复重或利旧平台标签可查看该处设备，再通过「总览范围」返回全场。浅色场坪按图保留周转空间，斜线表示以工艺占地概括的区域。

先启动本机服务。在安装了 Playwright Chromium 的环境中运行 `node check_cargo.mjs`，结果和各视图截图写入 `evidence/cargo`。用完整模型包运行 `node check_cargo_motion.mjs`，可检查九条支路、纸箱倾角、滚筒轴、回放和旧包兼容性。运行 `node check_cargo_field.mjs` 可检查全场坐标、供包端的实际网格间隙、链节承托、叉齿接触和卸货组板操作。录制当前演示使用 `node record_cargo.mjs`，需要可从命令行调用 FFmpeg。可以传入一个新 MP4 文件路径。连接地址和证据输出目录可分别通过 `AIRPORT_URL` 和 `AIRPORT_EVIDENCE` 设置。

设备图纸、坐标、实测结果、截图和影片随本机项目资料交付。源码中的注册、模型显示和回放使用米为单位。施工定位和设备选型以项目正式设计文件为准。
